# 采购审批办法 V1.0（虚构示例）

版本：V1.0。生效日期：2026年1月1日。适用范围：虚构组织的内部办公物资采购申请。仅为模板演示。

## 历史适用范围（虚构示例）

本版适用于2026年1月1日至2026年9月30日期间提交的申请。2026年10月1日起提交的申请执行《采购审批办法 V2.0》。新版本明确规定，2026年10月1日前已提交但未完成审批的申请继续按本版办理。

## 审批金额规则（虚构示例）

申请金额以含税总价计算。金额小于或等于5000元，由部门负责人审批；金额大于5000元，由部门负责人及财务负责人共同审批。恰好5000元属于第一档。不得拆分采购规避审批。

## 提交材料（虚构示例）

提交用途、物资清单、数量、含税总价和供应商报价。涉及软件订阅、个人信息处理或对外合同的事项不适用本简化办公物资流程，应另行确认适用制度。
