# 首页快捷问答（虚构示例）

本文仅用于模板演示，不代表用户单位实际制度。以下问答分别依据本示例包的项目验收、采购V2.0及差旅报销规则。正式替换资料时，应同步更新首页快捷问题及本问答文档，不让演示规则混入真实回答。

## 问：星河项目验收需要哪些材料？

答：六类基本材料为双方确认的需求清单、交付物清单及版本号、测试报告、遗留问题清单、用户操作说明、培训签到或培训记录。涉及数据迁移时还需迁移核对报告；不涉及迁移时在交付物清单中注明不适用及原因。验收确认单在验收通过后形成，不是申请验收前必须已签署的材料。依据《星河项目验收规范（虚构示例）》；材料齐全后3个工作日内组织检查，并非承诺3个工作日内完成全部验收。

## 问：2026年10月提交的办公物资采购申请，审批流程是什么？

答：按《采购审批办法 V2.0（虚构示例）》，2026年10月1日起提交的内部办公物资采购适用V2.0。先提交用途、物资清单、数量、含税总价与供应商报价，由部门负责人核查必要性；含税总价不超过3000元由部门负责人审批，大于3000元且不超过10000元由部门及财务负责人审批，超过10000元还需分管负责人审批。全部审批完成后方可下单。超过10000元原则上至少两家报价；唯一供应商需唯一来源说明并经财务负责人确认。不得拆单规避。软件订阅、个人信息处理、对外合同不适用该简化流程。10月之前已提交的申请仍按旧版，不按当前日期强行切换。

## 问：境内公务差旅报销有哪些容易遗漏的细节？

答：按《差旅报销指引（虚构示例）》，出差前完成申请审批；报销时提供已审批申请、行程单、合规发票及费用明细，住宿另附清单。抬头与报销主体一致，出行日期与申请一致，私人费用不纳入公务报销。结束后10个工作日内提交完整材料，需要延期应在截止前申请并获书面确认。住宿每人每晚按实际金额报销，常规上限400元，不是固定发放400元；多人同住不能重复报销。需要超标时应事先取得部门与财务负责人的书面确认，未提前确认不能承诺全额报销。本指引不包含餐补、交通等级或到账日期，不得自行补充。
