# 采购审批办法 V2.0（虚构示例）

版本：V2.0。生效日期：2026年10月1日。适用范围：虚构组织的内部办公物资采购申请。仅为模板演示。

## 替代关系与过渡规则（虚构示例）

本版替代《采购审批办法 V1.0》，适用于2026年10月1日及以后提交的申请。此前已提交但未完成审批的申请继续按V1.0办理。不能只根据当前日期决定旧申请的适用版本，应确认申请提交日期。

## 审批金额规则（虚构示例）

金额以含税总价计算。小于或等于3000元，由部门负责人审批；大于3000元且小于或等于10000元，由部门负责人及财务负责人共同审批；大于10000元，先由部门负责人及财务负责人审批，再由分管负责人审批。恰好3000元属于第一档，恰好10000元属于第二档。不得拆分采购规避审批。

## 流程与材料（虚构示例）

申请人提交用途、物资清单、数量、含税总价与供应商报价。部门负责人先核查必要性，再根据含税总价确定后续审批人。全部审批完成后方可下单。

超过10000元时，原则上提供至少两家供应商报价；只有唯一供应商时，可以提交唯一来源说明，由财务负责人确认后继续审批。本办法不规定审批人必须在几天内完成审批，也不保证采购到货时间。

## 不适用范围（虚构示例）

软件订阅、个人信息处理和对外合同事项不适用本简化办公物资流程，应另行确认相应制度。本示例库未提供这些制度。
