# 示例资料说明（虚构示例）

本知识库仅用于演示通用知识问答模板，所有组织、项目、流程、金额、日期和规则均为虚构示例，不代表任何真实机构的制度。

## 资料覆盖范围（虚构示例）

本示例包包含星河项目验收、采购审批旧版与新版、差旅报销规则。采购新旧版具有明确的适用日期和替代关系，用于测试版本识别。正式使用时，请将本文件和其他示例文件一起移除，上传自己的有效制度。

## 不包含的信息（虚构示例）

本包不包含真实员工信息、供应商名单、星河项目预算金额、付款账户、实际审批状态、对外服务承诺及完整单位制度目录。不能根据这些示例推断用户单位的实际规定。

## 正式资料的编写建议（模板使用说明）

每份制度建议包含标题、版本、生效日期、适用范围、负责人角色、具体流程、金额与时限、例外情况、废止或替代关系。避免上传密码、密钥和无关个人信息。不同权限的资料不要混放到一个面向所有访客的应用中。
